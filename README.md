# 🌌 Little Pink Cloud — Portfolio & Project Showcase

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A celestial‑themed, fully responsive portfolio site designed and built by **Pebbles McFadden**.  
This project showcases cloud engineering work, Azure projects, diagrams, creative UI design, and hands‑on technical exploration — all wrapped in a soft, dreamy aesthetic inspired by night skies, glowing gradients, and magical cloudscapes.

Live Site: **[https://littlepinkcloud.net/]**

---

## ✨ Overview

This portfolio serves as a central hub for my cloud engineering projects, Azure architecture diagrams, hands‑on labs, and creative technical work.  
It is built as a lightweight static site with custom UI components, a floating navigation panel, animated carousels, and modular project pages.

The goal:  
A space that feels magical, intentional, and deeply *me* — while still being clean, professional, and easy for recruiters and collaborators to explore.

---

## 🌟 Features

- 🌙 **Celestial UI theme** with soft glows, glassmorphism, and dreamy gradients  
- 🧭 **Floating navigation panel** with smooth scrolling and active‑link highlighting  
- 📸 **Custom-built image carousel** with captions, swipe support, and animated transitions  
- 📄 **Modular project pages** with architecture diagrams, walkthroughs, and screenshots  
- 📱 **Fully responsive layout** across desktop and mobile  
- ☁️ **Azure Static Web Apps deployment** with GitHub Actions CI/CD  
- 🔧 **Clean folder structure** for easy maintenance and expansion  

---

## 🧰 Tech Stack

- **HTML5**  
- **CSS3** (custom design system, animations, gradients, glassmorphism)  
- **JavaScript** (carousel logic, navigation interactions)  
- **Azure Static Web Apps**  
- **GitHub Actions** (automated deployment pipeline)

## 🚀 Local Development

This project is a simple static site — no build step required.

To run locally:

1. Clone the repository  
2. Open `index.html` in your browser  
3. Explore freely  

---

## ☁️ Deployment

This site is deployed using **Azure Static Web Apps**.

Every push to the `main` branch triggers:

- GitHub Actions build  
- Automatic deployment to Azure  
- Optional PR preview environments  

The workflow file lives in:
.github/workflows/azure-static-web-apps.yml
