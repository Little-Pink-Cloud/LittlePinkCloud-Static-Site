Services & Technologies Used

Azure VM VNet NSG Bicep Azure Monitor

Step-by-Step Walkthrough

1. Create Resource Group


az group create \
  --name my-rg \
  --location eastus

2. Deploy Bicep Template


az deployment group create \
  --resource-group my-rg \
  --template-file main.bicep

Key Configurations

Challenges & Solutions

  • Challenge: NSG rules blocked SSH access.
  • Solution: Added inbound rule for port 22 and validated via Azure Monitor logs.
